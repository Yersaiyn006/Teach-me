# Teach Me

Teach Me — оқу мәтінінен сұрақ-жауап карточкаларын жасайтын Django веб-қосымшасы. Материалдар мен карточкалар SQLite дерекқорында сақталады.

Жоба оқу және демонстрация үшін localhost-та іске қосылады. Аккаунт, кіру және материал иесін анықтау механизмі жоқ. Серверге қол жеткізе алатын адам сақталған материалдарды қарап, карточкаларды өзгерте алады.

## Орнату және іске қосу

Командаларды `manage.py` және `requirements.txt` тұрған жобаның негізгі бумасында орындаңыз. Жоба Django 5.2 және `python-dotenv` пайдаланады.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

PowerShell ортаны белсендіруге рұқсат бермесе, төмендегі командаларда `python` орнына `.\.venv\Scripts\python.exe` қолданыңыз.

macOS және Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Дайын миграцияларды қолданып, жергілікті серверді іске қосыңыз:

```bash
python manage.py migrate
python manage.py runserver 127.0.0.1:8000
```

Браузерде [басты бетті](http://127.0.0.1:8000/) ашыңыз.

Егер жергілікті `Flashcard` моделінде `is_verified` өрісі бар болып, оған миграция әлі жасалмаса, алдымен мына командаларды орындаңыз:

```bash
python manage.py makemigrations study
python manage.py migrate
```

## №8. DEMO режимі

Жобаның негізгі бумасындағы `.env` файлына мына мәнді қойыңыз:

```dotenv
TEACHME_MODE=demo
```

Басты бетте компьютерлік желілер туралы дайын мысал толтырылып тұрады. Мысалдың оқу мәтінін өзгертпей жіберіңіз. DEMO режимі осы мәтін үшін IP-адрес, DNS және маршрутизатор туралы үш дайын карточка қайтарады. Генерация кезінде Gemini API шақырылмайды және API кілті қажет емес. Дайын мәтін өзгерсе, DEMO генерациясы қабылданбайды.

Басты беттегі формада тақырып 120 таңбаға дейін, оқу мәтіні 80–12000 таңба болуы керек. Генерация валидациясы 3–8 карточканы, бірегей сұрақтарды және бастапқы мәтінде дәл кездесетін дәйексөздерді талап етеді. Сұрақтың шегі — 300 таңба, жауап пен дәйексөздің әрқайсысының шегі — 1600 таңба.

Бір карточка жарамсыз болса, бүкіл нәтиже қабылданбайды. Сақтау кезінде материал мен барлық карточка бір транзакцияда жазылады. Карточкалардың бірін сақтау сәтсіз болса, сол транзакциядағы барлық жазу кері қайтарылады.

### Қосымша LIVE режимі

LIVE режимі жаңа оқу мәтінінен карточка жасау үшін Gemini API пайдаланады. Сұраныс Python стандартты кітапханасындағы `urllib` арқылы жіберіледі.

```dotenv
TEACHME_MODE=live
GEMINI_API_KEY=YOUR_API_KEY
GEMINI_MODEL=YOUR_AVAILABLE_MODEL_ID
GEMINI_TIMEOUT_SECONDS=25
```

API кілті бар `.env` файлын репозиторийге жарияламаңыз. `.env.example` файлына құпия емес үлгі мәндерді ғана енгізіңіз.

## №9. Сақталған жинақ және карточка редакторы

Сәтті генерациядан кейін жинақ беті ашылады. Сақталған жинақты басты беттегі материалдар тізімінен қайта ашуға болады. Жинақтың URL үлгісі — `/sources/<pk>/`, мұндағы `pk` — материалдың ID нөмірі.

- **Жауапты оқу.** «Жауапты көрсету» бөлімін ашқанда жауап пен дәйексөз көрінеді. Толық конспект «Бастапқы оқу мәтіні» бөлімінде сақталады.
- **Өңдеу.** «Өңдеу» сілтемесі сұрақты, жауапты және дәйексөзді өзгерту формасын ашады. Дәйексөз бастапқы мәтінде дәл кездесуі керек. Форма жол соңының CRLF және CR пішімдерін LF пішіміне келтіреді. Жарамсыз дерек енгізілсе, форма қатені көрсетеді және енгізілген мәндер формада қалады. Сәтті сақтаудан кейін карточка қайта тексеруге жіберіледі.
- **Өшіру.** «Өшіру» сілтемесі растау бетін ашады. «Иә, өшіру» тек таңдалған карточканы жояды. «Бас тарту» жинаққа қайтарады. Қалған карточкалардың реттік нөмірлері сақталады. Соңғы карточка өшірілсе, жинақ беті бос күй хабарын және ашық конспектті көрсетеді.
- **Тексеру күйі.** Сұрақты, жауапты және дәйексөзді конспектпен салыстырып, «Карточканы тексердім» түймесін басыңыз. «Тексеруге қайтару» күйді қайтарады. Күйді студент қолмен белгілейді. Дәйексөздің мәтінде болуы оның қайдан алынғанын растайды. Жауаптың фактілік дұрыстығын студент бағалайды.
- **Сүзгі.** «Барлығы», «Тексеру керек» және «Тексерілген» сілтемелері тізімді сүзеді. Санауыштар бүкіл жинақ бойынша көрсетіледі. Бос сүзгіден «Барлығын көрсету» сілтемесі арқылы шыға аласыз.

| Маршрут атауы | URL | Әдіс |
|---|---|---|
| `home` | `/` | GET, POST |
| `source_detail` | `/sources/<pk>/` | GET |
| `card_edit` | `/cards/<pk>/edit/` | GET, POST |
| `card_delete` | `/cards/<pk>/delete/` | GET, POST |
| `card_review` | `/cards/<pk>/review/` | POST |

Жинақ бетін ашу мен сүзу дерекқордан оқиды. Өңдеу, өшіру және тексеру күйін өзгерту де сақталған карточкалармен жұмыс істейді. Бұл әрекеттер генераторды шақырмайды.

## Тексеру командалары

```bash
python manage.py check
python manage.py showmigrations study
python manage.py makemigrations --check --dry-run
python manage.py test study
```

`check` Django конфигурациясын тексереді. `showmigrations study` қолданылған миграцияларды көрсетеді. `makemigrations --check --dry-run` модель өзгерісіне миграция қажет пе екенін файл жасамай тексереді.

`test study` бөлек тест дерекқорында `study/tests.py` және `study/test_editor.py` сценарийлерін іске қосады. Бірінші файл DEMO генерациясын, жарамсыз нәтижені қабылдамауды, транзакцияның кері қайтуын және жинақ бетін оқуды тексереді. Екінші файл өңдеуді, өшіруді, тексеру күйін, сүзгілерді, 404 жауаптарын, CSRF қорғанысын және редактор әрекеттерінің генераторға жүгінбейтінін тексереді.

## Дерекқор қатесі

`no such table: study_source` қатесі кестенің, ал `no such column: study_flashcard.is_verified` қатесі бағанның қолданылып тұрған SQLite дерекқорында жоқ екенін көрсетеді. `python manage.py showmigrations study` арқылы миграция күйін тексеріп, дайын миграцияларды `python manage.py migrate` арқылы қолданыңыз.
